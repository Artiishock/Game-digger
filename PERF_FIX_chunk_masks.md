# Перф-фикс: убрать живые маски чанков (главный источник draw-call'ов)

> **Профит (ПОДТВЕРЖДЁН замером, 2 прогона):** с отключёнными масками
> fps **28 → 60 (стабильно)**, draws/кадр **~170 → ~65**, texBinds **~330 → ~160**.
> **Атлас предметов (`PERF_FIX_texture_atlas.md`) эту проблему НЕ решает** —
> проверено замером после его внедрения (draws не изменились).
>
> ## ✅ Шаг 1 ВЫПОЛНЕН — маски подтверждены как причина
> Прогон с `MEASURE_DISABLE_CHUNK_MASKS = true`: fps вырос с ~28 до **ровно 60**,
> draws упали в 2.5 раза. Узкое место — не счётчик draws, а оверхед `AlphaMaskPipe`
> (stencil push/pop на чанк каждый кадр). Туннель при этом не рисуется (маски его и
> резали) — ожидаемо для пробы. Осталось вернуть вырез туннеля через `erase`-bake (Шаг 2).

---

## 1. Корень (подтверждено по коду)

Туннель вырезается из земли так:
- в `maskRT` каждого чанка карвятся **чёрные** формы пути — [`_applyCavePathToChunk` → Tileworld.ts:1510](src/game/Tileworld.ts#L1510) (`clear:false`, накапливается по мере копания);
- `maskRT` вешается **живой маской** на контент: [`content.mask = maskSpr` Tileworld.ts:1435](src/game/Tileworld.ts#L1435) и [`topGrass.mask = grassMaskSpr` :1436](src/game/Tileworld.ts#L1436).

В PixiJS v8 живая sprite-маска идёт через `AlphaMaskPipe`: **каждый кадр** на каждый
маскированный объект — push маски, бинд её текстуры, рендер, pop, и **разрыв батча**.
Две маски × N активных чанков → взрыв draws/binds. Сами авторы это знают — коммент
[Tileworld.ts:1405](src/game/Tileworld.ts#L1405): *«each sprite-mask costs a GPU push/pop
per chunk per frame. -1 mask = -50% mask ops»* (они уже сняли третью, тёмную, маску).

Замеры (`metrics.json`, 2 прогона): idle 36 draws / 64 binds → копание 130–160 / 280–326.
CPU при этом 92% idle → упор чисто в GPU-стейт от масок.

## 3. Шаг 2 — настоящий фикс: запечь дырку в `earthRT` через `erase`

Контент чанка **уже** бейкается в `earthRT` — [`_bakeToRenderTexture` Tileworld.ts:595](src/game/Tileworld.ts#L595),
вызов на [:1338](src/game/Tileworld.ts#L1338). Значит, дырку можно пробить прямо в этой
текстуре, без живой маски.

### Суть
- **Было:** карвить чёрное в отдельную `maskRT` → вешать `content.mask`.
- **Стало:** карвить путь **прямо в `earthRT`** с `blendMode = 'erase'` (destination-out) →
  прозрачная дыра в самой текстуре земли. `content.mask = null`.

Карв инкрементальный (`clear:false`) — erase тоже инкрементальный, идеально ложится на
«копаю всё глубже». Стоимость переезжает с *каждого кадра для каждого чанка* на
*один раз при изменении туннеля для одного чанка*. Статичные чанки → нулевая per-frame
стоимость.

### Где править

**A. Сборка чанка** [Tileworld.ts:1388–1447](src/game/Tileworld.ts#L1388):
- не создавать `maskRT`/`maskSpr`, `grassMaskRT`/`grassMaskSpr` (или оставить под флагом);
- убрать `content.mask` / `topGrass.mask` (уже под флагом из Шага 1 — заменить флаг на постоянное);
- `content` = спрайт `earthRT` как есть (дыра будет внутри текстуры).
- ⚠️ **требует, чтобы бейк был активен** (ветка [:1338](src/game/Tileworld.ts#L1338)).
  Фолбэк-ветки без `earthRT` ([:1351](src/game/Tileworld.ts#L1351), [:1354](src/game/Tileworld.ts#L1354))
  под новый путь не годятся — либо всегда бейкать, либо оставлять им старую маску.

**B. Карв** [`_applyCavePathToChunk` Tileworld.ts:1456](src/game/Tileworld.ts#L1456):
- форма `g` сейчас заливается чёрным (`0x000000`) и рендерится в `maskRT` ([:1510](src/game/Tileworld.ts#L1510));
- заменить на: залить `g` непрозрачным (`0xffffff`, alpha=1), выставить `g.blendMode = 'erase'`,
  рендерить в `earthRT` чанка (передавать `earthRT` вместо `maskRT`):
  ```ts
  g.blendMode = 'erase'
  this.renderer.render({ container: g, target: earthRT, clear: false })
  ```
- то же для grass-полоски (нужно, чтобы grass тоже был в своей `RenderTexture`; сейчас
  `topGrassSpr` — спрайт текстуры травы, его придётся бейкать в RT, чтобы erase'ить).

### Подводные камни
- **Grass:** сейчас не в RT → либо бейкать его в RT (тогда erase работает), либо для grass
  оставить старую маску (grass — одна полоса сверху, дешевле, чем content). Прагматично:
  начать с content (главный объём), grass решить после замера.
- **Premultiplied alpha / фон RT:** `erase` корректно работает на RenderTexture с альфой;
  проверить, что `earthRT` создаётся с прозрачным фоном (по умолчанию да).
- **Сглаживание края:** живая маска и erase-bake дают чуть разный AA на кромке туннеля —
  визуально проверить (артефактов быть не должно, край и так пиксельный).
- **Ре-бейк чанка:** если земля перегенерируется (смена варианта) — дыры потеряются;
  убедиться, что чанки не ребейкаются после карва (сейчас не ребейкаются).

- [x] **ПРИЧИНА НАЙДЕНА (из исходника pixi 8.19, не гадание):**
  1. **Маска v8 читает КРАСНЫЙ канал, не alpha.** `mask.frag`: `a = alphaMul * masky.r`
     (default channel = "red"). Поэтому живая маска работает с opaque-чёрным тоннелем
     (r=0 → дыра). Мои попытки с `erase`/alpha были мимо канала — откачены.
  2. **`renderer.render({container})` делает контейнер КОРНЕМ render-group**
     (`AbstractRenderer.render` → `container.enableRenderGroup()`). А v8 применяет
     `.mask` **родителем** при обходе в дочерний — у корня собственная маска НЕ
     накладывается. Поэтому рендер `content` напрямую → маска игнорится → сплошная земля.
- [x] **ФИКС:** рендерить `content` внутри обёртки `_flattenWrapper` → content становится
  ребёнком, не корнем → его `.mask` применяется при обходе ([Tileworld.ts:1524](src/game/Tileworld.ts#L1524)).
  Carve вернулся к opaque-чёрному в maskRT (red-channel).
- [x] **Недостающее звено:** ре-флэттен висел на карве пещер, а тоннель режется через
  `scratchAt`→`_scratchWorldTunnelStamp`→`maskRT` ([Tileworld.ts:861](src/game/Tileworld.ts#L861)).
  Добавлен dirty-set: тронутые чанки помечаются ([:865](src/game/Tileworld.ts#L865)) и
  пересобираются раз за кадр ([:987](src/game/Tileworld.ts#L987)).

- [x] Отладочный `MEASURE_DISABLE_CHUNK_MASKS` удалён. `USE_BAKED_TUNNEL_MASK = true` (дефолт),
